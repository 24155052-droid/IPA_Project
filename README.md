## What this project does

Two ways of hiding data inside an image are implemented **from scratch in NumPy**
and compared under the same attacks and metrics:

| Method | Domain | Idea |
|---|---|---|
| LSB steganography | spatial | write payload bits into the k lowest bit planes |
| DCT-QIM watermarking | transform (8x8 block DCT) | quantization index modulation of one mid-frequency coefficient per block, with optional repetition coding |

Both can use a secret key that selects pseudo-random embedding positions.

The project measures:

1. **Capacity vs imperceptibility** of LSB (k = 1..4): PSNR, SSIM
2. **Robustness** of LSB, DCT-QIM (r=1) and DCT-QIM (r=4) against 17 attacks
   (JPEG, noise, blur, median, crop, rescale, brightness): bit error rate
3. The **delta trade-off** (invisibility vs robustness) of DCT-QIM
4. **Chi-square steganalysis** (Westfeld and Pfitzmann) of LSB embedding
5. A **colour image** (watermark in the luminance channel)

## Run it

```bash
pip install -r requirements.txt
python main.py          # runs every experiment, writes figures + results.json to results/
python -m pytest -q     # 18 unit tests
```

All experiments use fixed seeds, so the numbers are reproducible.

## Layout

```
main.py             runs all experiments
src/lsb.py          LSB embed / extract (+ text helpers, secret key)
src/dct_wm.py       DCT-QIM blind watermark embed / extract
src/attacks.py      JPEG, noise, blur, median, crop, rescale, brightness
src/steganalysis.py chi-square pairs-of-values test
src/metrics.py      MSE, PSNR, SSIM, BER, NC, entropy
tests/test_core.py  unit tests
images/             test images (scikit-image Cameraman and Astronaut, 256x256)
results/            figures and results.json written by main.py
report/             project report (Word and PDF)
```

## Data

No dataset is downloaded. The two test images are the standard Cameraman and
Astronaut images bundled with scikit-image (the Astronaut image is a NASA
photograph in the public domain), resized to 256x256. The attacks, noise and the
16x16 watermark ("SD") are generated by the code itself.

## Limitations

Two test images only; attacks are applied one at a time; geometric attacks that
need synchronisation (rotation, translation) are not handled by the scheme.
